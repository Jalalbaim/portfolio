Technical work spanning generative image editing, retrieval systems, and LLM alignment.

  • V-EditR 2025

    Reasoning-first image editor powered by Vision–Language Models

    An image editing pipeline that understands complex natural language instructions and applies precise, context-aware edits. Unlike conventional tools, V-EditR first reasons about scene context, spatial relationships, and object identities before modifying anything — handling instructions such as "remove the chair behind the table" or "make the person holding the phone wear a black jacket".

    Approach

    • Multi-stage pipeline: text → plan generation → object grounding → edit → validation
    • Spatial and relational reasoning ("next to", "behind", "holding")
    • Object grounding with GroundingDINO + SAM segmentation masks
    • Modular architecture with separate planners, validators, and verifiers

    Stack

    Python GroundingDINO SAM InstructPix2Pix ControlNet Stable Diffusion LLM Parser
    Jalalbaim/V-EditR
  • TrustRAG 2024

    Trustworthy Retrieval-Augmented Generation for the medical domain

    A medical-domain QA system built on hybrid dense + sparse retrieval with hallucination prevention. Uses ~230K Wikipedia medical passages. Hallucinated content is blocked and replaced with explicit, grounded refusal messages rather than silently returned to the user.

    Approach

    • Hybrid retrieval: dense (FAISS) + sparse (BM25) with score fusion
    • Cross-encoder reranking for improved passage relevance
    • NLI-based faithfulness verification — hallucinated sentences are blocked
    • Evaluated with RAGAS: Faithfulness, Answer Relevancy, Context Precision

    Stack

    Python FAISS BM25 e5-small-v2 MiniLM cross-encoder gemma3:4b (Ollama) nli-deberta-v3-base RAGAS
    Jalalbaim/TrustRAG
  • FocusFlow 2025

    Localized image editing via masked velocity blending — no manual masks required

    A novel editing method built on Stable Diffusion 3 that enables precise, localized edits using only text prompts. Extends the FlowEdit technique by automatically identifying which regions to modify via velocity field analysis, then applying masked velocity blending to confine edits to the relevant area.

    Approach

    • Automatic mask generation via velocity field differencing between source/target prompts
    • Masked velocity blending: V_blend = M · V_target + (1 − M) · V_source
    • Evaluated on 40 test cases: pose changes, background replacement, material/style edits
    • Best CLIP-T score (0.296) vs. FlowEdit and SDEdit baselines

    Stack

    Python 3.10+ PyTorch 2.x + CUDA Stable Diffusion 3 diffusers CLIP LPIPS

  • Direct Preference Optimization 2024

    DPO paper implementation for LLM alignment via preference learning

    A clean implementation of the Direct Preference Optimization algorithm for aligning language models with human preferences. Fine-tunes TinyLlama-1.1B on a sentiment classification task using preference pairs (chosen vs. rejected outputs) generated by gemma3:4b via Ollama as a judge.

    Approach

    • Full DPO pipeline: data preparation → SFT baseline → DPO fine-tuning → evaluation
    • Preference pair generation using a larger LLM as an automated judge
    • Faithful reproduction of the original DPO paper methodology (β = 0.1)

    Stack

    Python TinyLlama-1.1B Ollama + gemma3:4b DPO loss PyTorch

  • FlowEdit 2025

    FlowEdit paper implementation — text-guided image editing with flow-matching diffusion

    A faithful implementation of the FlowEdit paper, enabling precise text-guided image transformations using Stable Diffusion 3 via source and target text prompts — without retraining or fine-tuning any model. Used as the primary baseline in the FocusFlow evaluation.

    Approach

    • Reproduces the FlowEdit delta velocity blending approach
    • Configurable editing parameters: timesteps, guidance scales, averaging steps
    • Batch editing via YAML config; includes paper figure reproductions

  • RAG Assistant Agent 2024

    Multi-agent document QA system with citation guarantees and PII safeguards

    A document assistant that answers questions from internal files (PDFs, HTML, emails) with guaranteed citations and built-in PII/secrets detection. Exposes a FastAPI REST interface for ingestion and querying.

    Approach

    • Multi-agent pipeline: Retrieval → Reranker → QA → Citation/Verifier → Safety/PII → Composer
    • Hybrid retrieval: vector similarity (ChromaDB) + BM25 keyword search
    • Supports PDF, HTML, TXT, and .eml ingestion with Tesseract OCR fallback
    • Automatic PII/secret detection during ingestion and response generation
